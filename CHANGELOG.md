# Changelog

## 0.1.0 — 2026-11-02

First release of `sboard`, a local agent session organizer for a side terminal.

- Discover Claude Code, Codex, Grok and OpenCode sessions and group them by project.
- Show working, waiting, idle, error and done status from transcript activity.
- Jump to matching tmux panes, resume native sessions, and launch sessions in projects or fresh git worktrees.
- Persist pins, tags, read marks, archives and TUI preferences.
- Surface an attention queue and optional desktop notifications.
- Query sessions and source diagnostics through the CLI, including JSON output.
- Provide Linux x86_64/aarch64 and macOS Apple Silicon archives with SHA-256 checksums.

OpenCode support is fixture-tested; live OpenCode acceptance has not been verified.
